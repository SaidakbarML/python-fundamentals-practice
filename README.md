# Python Fundamentals Practice

A broad set of practice scripts and notebooks covering core and advanced Python concepts.

## Why this exists
General Python skill-building — this repo was originally named `simple-house-price-web-app`, but it's actually unrelated to house prices; it covers Python fundamentals instead.

## Topics covered
- OOP and polymorphism (`oop.ipynb`, `polymorphism.ipynb`)
- Decorators (`decorators.ipynb`)
- Exception handling (`exception_handling.ipynb`)
- File operations & logging (`file operations.ipynb`, `logging.ipynb`, `multilogger.ipynb`)
- Multithreading & multiprocessing (`multithreading.ipynb`, `multiprocessing.ipynb`, `advanced multi threading.ipynb`, `factorial_multiprocessing.ipynb`)
- Web scraping (`webscraping_multithreading.ipynb`)
- SQL basics (`working with Sql.ipynb`)
- A small Flask app (`app1.py`, `app2.py`, `flask/`)

## How to run
Each notebook/script is self-contained — open the one covering the topic you want and run it directly.
